# ビューアを開く

対象: $ARGUMENTS（省略時は最近更新したモデル）

1. 作業フォルダ `print3d/<モデル名>/` を探す（`resume` スキルの手順 1 と同じ）。
2. Python 環境: `bash "${CLAUDE_PLUGIN_ROOT}/runtime/setup_env.sh"` を実行し、最後の行の JSON の `python`（PY）と `runtime`（RT）を使う（展開されない環境では `find / -name setup_env.sh -path "*print3d-modeler*" 2>/dev/null | head -1`）。
3. ビューアを作り直す（モデルは作り直さない）:
   ```bash
   cd RT && PY -m p3d.viewer <model_dir>
   ```
   parts.json が無い・model.py より古い場合は、先に `cd <model_dir> && P3D_RUNTIME=RT PY model.py` を実行する。
4. アーティファクトを作るツールが使えれば、`viewer.html` の中身をそのままアーティファクトとして表示する。あわせて必ずファイルへのリンクも示す（Cowork では `computer://<絶対パス>`。ブラウザで開けばオフラインで動く）。
5. 使い方を短く添える:
   - 左ドラッグで回転、ホイールで拡大縮小（カーソル位置へ寄る）、右ドラッグで移動、ダブルクリックでその点を回転の中心にする。
   - パーツにカーソルを合わせると名前（P1 台座 など）が出る。方向（上下・前後・左右）と合わせて、チャットで「P2 背もたれを上に 10mm」のように指示できる。
   - 右上の「パーツ・表示」でパネルを開くと、パーツ（複数オブジェクトならオブジェクトごと）の表示/非表示（半透明）、部位ラベル・方向・サポートが要りそうな面・1円玉の表示を切り替えられる。
   - 「印刷の向き」ボタンで印刷時の置き方と造形範囲を確認できる。
